# Azure Architecture Copilot Documentation

Welcome to the Azure Architecture Copilot documentation. This project aims to assist in analyzing, designing, and implementing Azure workloads based on business unit requirements while adhering to the Cloud Adoption Framework (CAF) and the Azure Well-Architected Framework (WAF).

## Overview

This documentation provides guidelines and templates for validating requests, documenting architectures, and ensuring best practices in Azure workload implementations.

## Contents

- [CAF Validation Checklist](../templates/caf-validation-checklist.md): A checklist for validating requests against the Cloud Adoption Framework.
- [WAF Validation Checklist](../templates/waf-validation-checklist.md): A checklist for validating requests against the Azure Well-Architected Framework.
- [Architecture Review Template](../templates/architecture-review-template.md): A template for conducting architecture reviews of Azure workloads.
- [Workload Request Template](../templates/workload-request-template.md): A template for documenting workload requests from business units.
- [Mermaid Diagram Template](../diagrams/architecture-template.mmd): A template for visualizing the architecture of Azure workloads.

## Getting Started

To get started with the Azure Architecture Copilot, follow the instructions in the [copilot instructions](../../.github/copilot-instructions.md) file. This will guide you through the process of analyzing and implementing Azure workloads effectively.

## Documentation Format

This documentation is available in both Markdown and HTML formats. The HTML version can be found in the `docs/html` directory, while the Markdown version is located in the `docs/markdown` directory.

For any further assistance or contributions, please refer to the README file for more information.
